# ============================================================================
# RATTLE GOLF
#
# This repo had no .gitignore at all until the native packaging batch, which was
# survivable while the only dependency was a test harness. It stopped being
# survivable when Capacitor and the iOS toolchain arrived: a single `git add .`
# on the Mac would otherwise commit node_modules, DerivedData and Xcode user
# state into a repository that has to stay public and cloneable.
#
# THE RULE HERE: ignore what a machine GENERATES, keep what a fresh clone NEEDS.
#
# Note the deliberate omission - ios/ is NOT ignored. See the block at the end.
# ============================================================================

# ---- Dependencies ----------------------------------------------------------
node_modules/
.npm/

# ---- npm / yarn logs -------------------------------------------------------
npm-debug.log*
yarn-debug.log*
yarn-error.log*
.pnpm-debug.log*

# ---- Generated build output ------------------------------------------------
#
# Both are produced deterministically from committed source:
#   dist/    -> node build-shell.js       (the two product deployments)
#   www/     -> npm run mobile:sync       (the 31-file Consumer native bundle)
#
# Committing them would mean every content change landed twice in the diff, and
# a stale copy could silently disagree with its source. Cloudflare Pages builds
# from source, and `npx cap sync ios` regenerates www/app before every copy.
dist/
www/

# ---- Secrets ---------------------------------------------------------------
#
# No .env file exists in this project today - Firebase web config is public by
# design and lives in the page source, protected by database.rules.json rather
# than by secrecy. These lines are here so that if one is ever introduced, it
# cannot be committed by reflex.
.env

# ============================================================================
# iOS / XCODE
#
# DECISION: the native project IS source-controlled. Ignore only what Xcode
# regenerates or what is specific to one machine and one user.
#
# Everything below this line is generated, per-user, or per-machine. Nothing
# below is needed to build the app on a fresh clone.
# ============================================================================

# Per-user Xcode state: window layout, breakpoints, selected scheme, last
# device. Different on every machine, changes constantly, means nothing to
# anyone else, and is the single largest source of noise in an iOS repo diff.
xcuserdata/
*.xcuserstate
*.xcuserdatad/

# Xcode build products and intermediates.
build/
DerivedData/
*.moved-aside
*.hmap
*.ipa
*.dSYM.zip
*.dSYM

# Swift Package Manager resolved state and checkouts. Capacitor 8 uses SPM
# rather than CocoaPods - there is no Podfile and no .xcworkspace, which is
# expected, not a defect.
.swiftpm/
.build/
Packages/
ios/App/.swiftpm/

# Capacitor copies the web bundle into the native project on every `cap sync`.
# It is a build artifact of www/app, which is itself generated - committing it
# would version the same HTML a third time.
ios/App/App/public/

# Written by `cap sync` from capacitor.config.ts. The .ts file is the source of
# truth and IS committed; this is its compiled output.
ios/App/App/capacitor.config.json

# ---- iOS files that are DELIBERATELY NOT ignored ---------------------------
#
# Listed here so nobody "tidies them up" later. Every one of these carries
# App Store configuration that cannot be regenerated from capacitor.config.ts:
#
#   ios/App/App.xcodeproj/project.pbxproj   signing, version, build number,
#                                           deployment target, capabilities
#   ios/App/App/Info.plist                  display name, permissions strings
#   ios/App/App/Assets.xcassets/            the approved 1024 AppIcon
#   ios/App/App/Base.lproj/                 launch screen
#   ios/App/App/AppDelegate.swift           app entry point
#   ios/App/Podfile / Package.swift         dependency declarations
#
# Regenerating ios/ from scratch on each machine would discard all of it and
# make an archive irreproducible. See NATIVE-IOS-RELEASE-CHECKLIST.md.
